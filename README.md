# 🌐 DevClip

웹 페이지의 코드 블록을 원클릭 복사하고, 스니펫으로 로컬 저장태그·검색하는 개발자용 Chrome 익스텐션입니다.

## ✨ 주요 기능

- 📋 웹 페이지 코드 블록 원클릭 복사
- 💾 코드 스니펫 로컬 저장 (Chrome Storage)
- 🏷️ 태그 기반 분류
- 🔍 제목/코드/태그 통합 검색
- 🌐 출처 URL 자동 저장
- 🗣️ 언어 자동 감지

## 🛠️ 기술 스택

- Chrome Extension (Manifest V3)
- Vanilla JavaScript
- Tailwind CSS (Popup UI)
- Chrome Storage API
